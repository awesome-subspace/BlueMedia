# 价目与售价

读取当前账户适用的计价规则，用于自行核算成本或在自己的产品里展示价格。

| 接口 | 用途 |
| --- | --- |
| [我的价目表](get-v1-pricing-rates.md) | 当前账户适用的分国家/分类费率。 |
| [我的售价策略](get-v1-pricing-tariff.md) | 当前账户适用的售价策略。 |

金额同样是最小货币单位的整数。实际扣费记录见[账本流水](get-v1-credit-account-ledger.md)。
