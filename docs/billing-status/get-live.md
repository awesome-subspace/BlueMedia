`GET /live`

进程存活检查。

:::note[鉴权]

此接口不需要 API Key。

:::

## 请求

Base URL：`https://api.bsptest.com`

## 响应

| 状态码 | 说明 |
| --- | --- |
| `200` | OK |
| `4xx` | 客户端错误 |

通用错误信封及处理建议见[错误码](../guides/error-codes.md)。

## 补充说明

只做进程存活检查，恒定返回成功，不触达数据库或 Redis，因此拿不到"服务能正常处理请求"的信号，只用来判断进程是否还活着（容器探针用）。
