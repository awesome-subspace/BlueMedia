散落在各指南里的限制集中在这里，方便排查「为什么被拒了」。每行都标明这条限制**由谁施加**——平台侧的可以联系我们，Meta 侧的只能等或改流程。

## 请求限流

| 限制 | 来源 | 超限表现 | 怎么处理 |
| --- | --- | --- | --- |
| 每个 API Key 对应账户 **600 条/分钟** | 平台 | `429 RATE_LIMITED` | 退避后重试，`retryable: true` |
| 客户侧邀请页接口按**来源 IP** 限流 | 平台 | 429 | 这组接口不挂 API Key，token 本身是凭据 |
| Meta 接口限流（码 `4` / `80007`） | Meta | 消息失败码 `META_RATE_LIMIT` | 平台自动退避重试，无需干预 |
| Cloud API 吞吐上限（码 `130429`） | Meta | `META_THROUGHPUT_LIMIT` | 平台自动重试 |
| 同一发送号码对同一收件号码短时间发送过多（码 `131056`） | Meta | `PAIR_RATE_LIMIT` | 平台自动重试 |

:::warning

`ENGAGEMENT_COOLDOWN`（429）**不是**可退避重试的限流。该收件人触发了 Meta 人均互动上限（131049），平台在本地 24 小时冷却期内直接拒绝再发模板——**24 小时内重试会延长 Meta 的封禁**。请等待或更换收件人。

:::

## 号码生命周期

| 限制 | 来源 | 说明 |
| --- | --- | --- |
| **72 小时内最多 10 次** register/deregister | Meta | 超限返回 `133016`，并封禁该号码 72 小时的注册能力。调试接入流程时不要拿同一个号码反复注册。 |
| 显示名称 **30 天内最多 10 次**修改 | Meta | 提交后进入审核，通过后**必须重新 register** 才真正同步。 |
| 验证码约 **10 分钟**有效、一次性 | Meta | 多次失败可能触发临时限制。 |
| 两步验证无法通过 API 关闭 | Meta | 只能在 WhatsApp Manager 手动关闭；接口只能设新值。 |

## 内容与媒体

| 限制 | 来源 | 说明 |
| --- | --- | --- |
| 上传接口单文件 **5 MB 硬限制** | 平台 | 超过直接 `400`。大于 5 MB 的音视频和文档只能改用 `link` 方式让 Meta 自取。 |
| 图片约 5 MB / 音视频约 16 MB / 文档约 100 MB | Meta | **在投递阶段**校验，发送接口不预检——超限消息会先拿到 `202`，之后才通过状态回调变成 `failed`。 |
| Meta 媒体 id 通常**几天后失效** | Meta | 不要把同一个 id 当长期素材库用。 |
| 媒体临时下载 URL **5 分钟**过期 | Meta | 需长期保存请走[代理下载](../templates-flows-media/get-v1-media-id-content.md)。 |
| 一条 `contacts` 消息最多 **257 个**联系人 | Meta | — |
| 单个 Flow 最近**一小时 10 条**消息 | Meta | 超限 `FLOW_THROTTLED`（132069），需先修正 Flow，重发无用。 |

## Webhook

| 限制 | 来源 | 说明 |
| --- | --- | --- |
| 常规投递单次超时 **10 秒** | 平台 | 返回 `2xx` 视为成功 |
| 验证/测试挑战超时 **5 秒**，响应体最多读 **4 KB** | 平台 | 比常规投递短，因为调用方在同步等结果 |
| 重试 **7 次、合计 8 次尝试**，窗口约 **38.6 小时** | 平台 | 固定表而非指数退避，详见[幂等与重试](idempotency.md) |
| 自定义 secret **至少 16 字符** | 平台 | 不填则平台生成 `whsec_` 开头的随机值 |
| 端点 URL 必须 https、不能解析到内网 | 平台 | **每次投递前会再解析一次**，事后改指内网同样被拦 |

## 其它取值约束

| 字段 | 约束 |
| --- | --- |
| `Idempotency-Key` | ≤200 字符 |
| 邀请 `expiresInSeconds` | 默认 1800，可配 300–86400（最长 24 小时） |
| 账本 `days` | 只接受 7 / 30 / 90，其它值按 30 处理 |
| 模板消息 `components.parameters` | 数量与顺序必须与模板声明**完全一致** |

## 平台会自动重试哪些失败

以下消息失败码标记为「平台自动重试」，调用方**不需要**自己重发：

`INTERNAL`、`META_RATE_LIMIT`、`META_SERVICE_UNAVAILABLE`、`META_THROUGHPUT_LIMIT`、`PAIR_RATE_LIMIT`、`PHONE_SEND_RESTRICTED`、`UPSTREAM_META_ERROR`、`WABA_MAINTENANCE_MODE`。

其余码 `retryable: false`——重试会得到一模一样的结果，请按 `customerAction` 决定下一步。全表见[错误码](../guides/error-codes.md)。
